Heex Technologies builds the Smart-Data Platform, an event-based data management solution for autonomous systems, robotics, and ADAS/AD vehicles. Instead of moving raw big data off fleets, Heex lets engineering teams define Smart Events with pre-set triggers so software agents capture only the most relevant, context-rich data ("Smart-Data") directly at the edge or in the cloud. The platform spans a Heex Agent/SDK deployed on robots and vehicles (Ubuntu x86_64/ARM, ROS/ROS2), a Heex CLI for operating the SDK and Heex Cloud, and a web platform for triggers, events, recordings, and fleet monitoring. It is used across AMRs, industrial robots, smart mobility, and off-road autonomy, with customers and partners including NVIDIA, Siemens, RATP, Vinci, Stanley Robotics, Apex.AI and Helm.AI. Backed by Techstars, Google for Startups, and AWS Activate.
